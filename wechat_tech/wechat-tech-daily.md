# 微信公众号 — 科技板块日报 自动化提示词模板

> 用途：将已清洗的科技资讯结构化数据交给 AI，稳定生成适合微信公众号发布的日报初稿。

---

## 设计原则

1. 优先稳定生成，同时保证排版精美
2. 模型只负责筛选、归纳、改写和组织结构
3. 输出统一为 Markdown（允许少量 HTML 用于图片居中），后续再转微信公众号 HTML
4. 原始数据不足时允许跳过栏目，禁止为了凑结构编造内容
5. 图片只使用已确认可发布的稳定地址

---

## 输入要求

推荐在调用 LLM 前先把网页清洗成结构化 JSON。

推荐输入结构：

```json
{
  "date": "2026-05-04",
  "topic": "科技板块日报",
  "news_items": [
    {
      "title": "新闻标题",
      "source": "媒体名",
      "published_at": "2026-05-04 09:30",
      "url": "https://example.com/news/123",
      "summary": "清洗后的正文摘要",
      "tags": ["AI", "芯片"],
      "importance_hint": "高",
      "images": [{ "url": "https://cdn.example.com/image.jpg", "desc": "图片说明", "usable": true }]
    }
  ],
  "market_data": { "a_share": [], "us_stock": [] },
  "policy_updates": [],
  "tomorrow_watch": []
}
```

```md
# 角色
你是一名资深科技媒体编辑，擅长撰写适合微信公众号发布的科技日报。文章需要信息密度高、排版精美、可读性强。

# 目标
根据我提供的结构化科技资讯数据，生成一篇科技日报初稿。

# 筛选要求
1. 从原始资讯中筛选出当天最值得关注的 5 条新闻。
2. 同一事件有多个来源时合并为 1 条。
3. 优先选择：
   - 头部科技公司动态（苹果、谷歌、微软、亚马逊、Meta、字节、华为、小米等）
   - AI / 芯片 / 半导体 / 消费电子 / 云计算 / 互联网平台的重要更新
   - 融资、合作、产品发布、政策变化、商业化进展
   - 对行业从业者有实际影响的信息
4. 低信息密度、标题党、软文感明显的内容不要入选。
5. 宏观社会新闻（假期出行、农民工收入、外交事件等）除非与科技直接相关，否则不要入选。
6. 不要照抄原文，要做信息压缩、去重和改写。
7. 保持客观专业，不写投资建议，不使用夸张词。
8. 信息不足时跳过栏目，不要补写猜测，**省略时不要输出任何占位文字**。

# 图片规则
1. 只可使用输入中标记为 usable=true 的图片。
2. 全文最多插入 3 张图，没有合适图片则不插。
3. 图片使用 HTML 居中：
   <div style="text-align: center; margin: 16px 0;">
   <img src="图片URL" style="max-width: 100%; height: auto; border-radius: 8px;" />
   <p style="color: #888; font-size: 12px; margin-top: 6px;">图片说明</p>
   </div>
4. 没有可靠图片就不要插入。

# 排版风格
1. 使用 emoji 增强视觉层次（🔥 💻 🤖 🚗 📊 ✅ 🏷️ 等），但不过度。
2. 关键数据（金额、型号、数字）用 **加粗** 标注。
3. 每条核心要闻后附「市场影响」或「行业观察」分析（用表格或引用框）。
4. 适当使用 Markdown 表格展示结构化信息（产品参数、价格档位等）。
5. 文风适合手机阅读，段落短，信息密度高。
6. 对数字、金额、型号、日期等关键信息要保留。
7. 原始信息未披露细节时，写"原始信息未披露"。
```

## 工作流摘要

1. 采集科技网站页面
2. 用清洗脚本提取结构化 JSON
3. 将 JSON 填入 `{{structured_news_payload}}`
4. 调用 LLM 生成 Markdown 初稿
5. 转换为微信公众号 HTML
6. 上传封面和草稿

---

## 不建议做的事

1. 不要把整页 HTML 原样喂给模型
2. 不要要求模型直接输出 HTML 和 Markdown 混合格式
3. 不要要求模型在信息不足时强行补齐"明日关注"或"板块表现"
4. 不要直接使用新闻站原图作为正式发布图片来源
5. 不要在提示词里堆过多视觉样式要求，优先保证信息筛选和摘要质量
